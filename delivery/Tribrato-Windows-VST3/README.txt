Tribrato 1.0.0 - Windows VST3

Install:
1. Close your DAW.
2. Copy the Tribrato.vst3 folder into:
   C:\Program Files\Common Files\VST3
3. Open your DAW and rescan VST3 plugins if it does not appear automatically.

Package contents:
- Tribrato.vst3

Notes:
- This is a 64-bit Windows VST3 plugin.
- Keep the Tribrato.vst3 folder intact. The files inside it are part of the plugin bundle.
